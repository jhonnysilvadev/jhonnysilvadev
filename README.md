## 👋 Sobre mim

Sou o **Jhonny**, desenvolvedor Front-End Junior. Gosto de fechar o ciclo completo de um projeto: desenho a interface no **Figma**, construo com **HTML, CSS, JavaScript/TypeScript e React**, e quando preciso de uma base sólida por trás, recorro a **PHP com Laravel**.

Curto trabalhar em coisas que eu mesmo uso e posso mostrar — por isso mantenho meus projetos pessoais no ar, como o [jhonnysilva.pt](https://www.jhonnysilva.pt) e o [musicpreview.jhonnysilva.pt](https://musicpreview.jhonnysilva.pt).
